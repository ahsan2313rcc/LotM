# Lord of the Mysteries — Tarot Card Game (React + Vite)

A playable 78-card Tarot trick-taking game featuring 22 Major Arcana Pathways, 198 Sequence abilities & Acting Conditions, 22 Chaos Events with X-card Grave Recycling, and an interactive **Ability & Rules Demo Lab**.

## Run Locally
```bash
npm install
npm run dev
```

## Push to GitHub (`https://github.com/ahsan2313rcc/LotM`)
```bash
git init
git add .
git commit -m "Initial commit: LoTM Tarot Card Game + Ability Demo Lab"
git branch -M main
git remote add origin https://github.com/ahsan2313rcc/LotM.git
git push -u origin main
```
